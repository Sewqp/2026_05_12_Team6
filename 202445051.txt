교수는 성적입력(교수id, 학생id)(자바, DB, 보안)을 입력한다.
반드시 교수id를 체크한다. (교수id는 inha)

총점과 평균을 계산한다.

교수는 학점조회 기능을 수행한다.
반드시 교수id를 체크한다.

학점 기준:
- 90 이상 A
- 80 이상 B
- 80 미만 C

모든 명칭은 한글로 작성한다.
(use case명, 클래스명, 속성명, 행위명)
데이터타입만 영문 사용한다.

다음 항목을 작성한다.
- 유즈케이스 다이어그램
  (성적입력, 학점조회, 교수체크)

- 클래스 다이어그램
  (교수(교수체크), 성적(성적입력, 학점조회),
   Add_Sungjuk_UI, Search_Sungjuk_UI)

- 순차도
  (성적입력, 학점조회)

- 순차도 기반 Java 코드 구현

- JSP 실행 코드 작성
